# SideKit FAQ

> ### What is SideKit?
SideKit is an independent Sideloading toolkit and platform provider.

We help hobbiest or owners start their own Sideloading "AppStore" in minutes by providing a fully customizable iOS App, Customizable Landing page, Dashboard for operators, and the rest of the ecosystem.

Our iOS App includes on-device IPA signing, modification, tweak injected & extraction as well as serving operator provided IPA's and server-sided signing.
We use the latest technologies and can proudly say we have one of the most versitile and efficient app.
